2Display colours (optional)

Colour-managed apps (Photoshop, Lightroom, Chrome, Edge) need to know your screen's red, green, blue and white. Without this step the profile assumes standard sRGB. To read your screen's factory values, open PowerShell (Start → type PowerShell), paste this command and press Enter:

Get-CimInstance -Namespace root\wmi -ClassName WmiMonitorColorCharacteristics | ForEach-Object { foreach ($c in 'Red','Green','Blue','DefaultWhite') { "$c $($_.$c.X) $($_.$c.Y)" } }
Using standard sRGB until you paste values.

5Install it in Windows (about 1 minute)

  1. Press Win + R, type colorcpl and press Enter. Colour Management opens.
  2. Devices tab: check the Device is your laptop screen, then tick Use my settings for this device.
  3. Click Add…, then Browse…, pick the downloaded .icc file and click Add.
  4. Select it in the list and click Set as Default Profile.
  5. Advanced tab → Change system defaults… → Advanced tab → tick Use Windows display calibration → Close.
  6. The screen changes at once: mid greys get slightly brighter.

If nothing changes: turn off Automatically manage colour for apps and HDR in Settings → System → Display, then repeat step 5. To undo, remove the profile in the same Devices tab, or untick Use Windows display calibration.

6Check that it worked

  1. Keep the profile on. Plug in the charger.
  2. Open the laptop page and pair the iPhone again.
  3. On the phone, run Find null point.
  4. Before calibration your screen nulled near v 190 (gamma 2.4). With the profile working it should land near v 186 (gamma 2.2). Send me the result.
