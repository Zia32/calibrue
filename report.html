What this report covers

Calibrue measures the screen's tone response (gamma) and grey balance with the iPhone camera by comparison, which needs no absolute colour sensor. It does not measure brightness in nits, contrast, or colour gamut; gamut figures come from the screen's factory data (EDID). The white point is set by eye with Match the white.
