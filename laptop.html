Optional: add your screen's colours (for Photoshop, Lightroom, browsers)

Paste the four Chromaticity lines from HWiNFO (Monitor → your laptop screen), or the output of the command on the profile page. Without them the profile assumes standard sRGB.

Install (about 30 seconds)
  1. Open the downloaded Install Calibrue profile.cmd.
  2. If Windows says it protected your PC: More info → Run anyway. (It warns about every downloaded script.)
  3. Click Yes when Windows asks for permission. The screen changes when it finishes.
  4. Restart the browser, open this page again and pair. Then tap Verify on the iPhone.
Install by hand instead
  1. Press Win + R, type colorcpl, Enter.
  2. Devices tab: tick Use my settings for this device. Remove any older Calibrue profile.
  3. Add… → Browse… → pick → Add → Set as Default Profile.
  4. Advanced tab → Change system defaults… → Advanced → tick Use Windows display calibration → Close.
