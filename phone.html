Calibrate this laptop

  1. Laptop on the charger and switched on for 20 minutes (screens shift while warming up), room dimmed. External monitor? Drag the laptop page onto it and press F for fullscreen there; the profile is made for that screen.
  2. Windows: Settings → Display → Brightness → Change brightness based on content: Off.
  3. If a Calibrue profile is installed: colorcpl → Advanced → Change system defaults → untick Use Windows display calibration.
  4. Rear camera flat on the laptop's centre square, this screen facing you. Touchscreen laptop: put a thin cloth (microfibre) between the phone and the screen so it doesn't register as touches. Keep still for about 7 minutes.
